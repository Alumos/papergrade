# 英语答题卡版式冻结说明

用户示例风格作为视觉基准：A4上下双联；每个题组有题号横向排布，选项按列对齐；A/B/C、A/B/C/D、A/B/C/D/E/F/G均可；每个选项对应独立空心方框/色块，2B涂黑，不在采样区域印字。听力、阅读、七选五、完形/语法等section用清晰组标题分隔。

用户指定学号固定4位数字：例如19班32号填写1932。学号矩阵保留前导零语义（若业务允许以字符串显示），发布时所有参与学生必须4位ASCII数字，否则拒绝发布，不自动补位。

物理尺寸、定位、半A4双联、OMR坐标由versioned manifest生成；题量/选项超过版式容量时拒绝发布，不压缩到难以涂写。真实打印、2B、手机光线和七选项密度必须单独验收。
